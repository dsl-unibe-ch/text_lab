  2. 02

    Request

    Ask for charts, statistical tests or both, in your own words. Name the columns, and the chart or the test if you know it.

    Left empty, the agents explore the table: a few interactive charts of how its columns are distributed and related.

    What the agents can do
    Interactive charts
    Histograms, scatter plots, box plots, line and bar charts, scatter matrices and correlation heatmaps, to zoom and point at in the browser. The default.
    Figures
    Static, publication-ready images (PNG, 300 dpi), pair plots and word clouds. Ask for "static" or "publication" figures.
    Statistics
    Correlations, group comparisons (t-test, ANOVA, Mann-Whitney, Kruskal-Wallis), associations of categories (chi-square, Fisher) and linear and logistic regression, with their assumptions checked where it applies.

    A supervisor plans your request and hands it to an agent for each; they work at the same time. When no ready-made chart fits, an agent writes its own code, which runs sealed off with only a copy of your table.
